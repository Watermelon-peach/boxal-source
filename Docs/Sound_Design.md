## 리소스 준비 시 주의사항

### 1. 박스몬 파괴음이 제일 까다롭다
숙련 플레이어는 **R25+에서 라운드를 3초에 클리어**한다. 즉 이 소리가 **초당 여러 번** 울린다.
- 길이 **0.3초 이내**, 잔향 적게
- 재생 시 **피치 랜덤화**(±10~15%)가 사실상 필수 — 같은 소리가 반복되면 매우 빨리 피로해진다
- 저음이 두꺼우면 겹칠 때 뭉개진다. 가볍고 건조한 톤 권장

### 2. LowHP 경고는 "상태"라서 결정이 필요하다
`AlertManager`의 LowHP는 한방컷 상태에 **진입/이탈**하는 상태값이지 순간 이벤트가 아니다. 두 방식 중 선택:
- **단발**: 상태 진입 시 1회만 재생 (조용함, 놓치기 쉬움)
- **루프**: 상태 지속 중 계속 재생 (긴박함, 과하면 스트레스)

권장은 **진입 시 단발 + 시각 경고는 이미 있는 CanvasGroup 유지**. 루프는 후반 라운드에서 상시 켜져 있을 수 있어 위험.

### 3. 파일 수를 줄이는 법
- 피치/볼륨 변조로 변화를 주면 **1개 파일로 여러 상황 커버** 가능 (예: 일반몹/보스 타격을 피치로 구분)
- 13·14번(보스/왕보스 경고)도 같은 소스의 피치·레이어 차이로 처리 가능

### 4. 포맷 / 임포트 설정 (모바일)
| 용도 | 포맷 | Load Type | Compression |
|---|---|---|---|
| SFX (짧음) | `.wav` | Decompress On Load | ADPCM 또는 PCM |
| BGM (루프) | `.ogg` | **Streaming** | Vorbis |

BGM을 Decompress On Load로 두면 메모리를 크게 먹으니 반드시 Streaming.

### 5. 라이선스
상업 배포 계획이 있으면 CC0 또는 상업 이용 허용 라이선스만 쓸 것.
무료 소스: Kenney(CC0), freesound.org(라이선스 개별 확인), Sonniss GDC 번들(로열티 프리).

## 진행 순서

1. **Title / Loading 씬 제작** ← 현재 여기
2. 위 목록으로 리소스 확보 (Tier 1부터)
3. `MMSoundManager` 기반 오디오 시스템 연결 (BGM/SFX 트랙 분리)
4. `SettingsPanelUI` — 볼륨 슬라이더 + 진동 토글

**3번이 4번보다 먼저인 이유**: 소리가 없으면 볼륨 슬라이더가 동작하는지 검증할 방법이 없다.
움직여도 아무 변화가 없는 것과 버그로 안 먹는 것을 구분할 수 없어, "되는 것처럼 보이는 미완성"이 된다.

진동 토글은 `NiceVibrations`가 햅틱을 코드로 생성하므로 리소스 없이 지금도 가능하다.
다만 설정 패널을 두 번 건드리게 되므로 한 번에 하는 편을 권한다.
